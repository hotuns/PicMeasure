# Implementation Plan: Tree Branch Image Measurement

**Branch**: `001-branch-image-measure` | **Date**: 2026-04-27 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/001-branch-image-measure/spec.md`

---

## Summary

Build a Python CLI tool (`picmeasure`) that measures tree branch dimensions
from photographs. A physical ruler in each photograph provides the scale
reference. The tool detects the ruler via Hough-line + peak-detection,
segments branches using MobileSAM, extracts width/length measurements via
skeleton analysis, and exports results as JSON and CSV. All parameters are
configurable via TOML. Batch processing of image directories is first-class.

---

## Technical Context

**Language/Version**: Python 3.11+
**Primary Dependencies**:
- `opencv-python-headless` — image I/O, edge detection, Hough transform,
  camera calibration, image annotation
- `scipy` — 1D peak detection for ruler tick marks
- `scikit-image` — skeletonization for branch centerline extraction
- `mobile-sam` / `segment-anything` — branch segmentation (MobileSAM default)
- `typer` — CLI framework with type annotation support
- `pydantic-settings` — config management with TOML loading and validation
- `numpy` — array operations throughout pipeline
- `pytest` + `pytest-cov` + `pytest-regressions` — testing
- `mypy` + `opencv-stubs` — static type checking
- `ruff` — linting and formatting

**Storage**: File system only — no database.
Input: image files. Output: JSON/CSV results + annotated images.

**Testing**: pytest; ≥90% line coverage enforced via pytest-cov in CI;
regression images managed by pytest-regressions

**Target Platform**: Desktop/laptop (Windows, macOS, Linux); no mobile/embedded

**Project Type**: CLI tool (single-package Python project)

**Performance Goals**: ≤30s per 12MP image on a modern CPU (MobileSAM);
batch mode with configurable parallel workers

**Constraints**: No internet connection required at runtime (model weights
pre-downloaded); all parameters configurable; batch mode interruptible and
resumable

**Scale/Scope**: Single researcher to small team; images 1–10,000 per batch
